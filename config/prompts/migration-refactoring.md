Контекст:
CRM-система на Spring Boot 2.7 с блокирующим Spring MVC.
Текущий стек: Java 17, Spring Boot 2.7, Spring Data JPA, Hibernate.
Целевой стек: Java 21, Spring Boot 3.2, Spring WebFlux, R2DBC.
Масштаб: 50 REST endpoints, 30 JPA entities.

Задача:
Создай план постепенной миграции с Spring MVC на WebFlux.

Требования:
- Миграция должна быть инкрементальной (по модулям)
- Продакшен работает 24/7, нельзя останавливать сервис
- Обратная совместимость API на переходный период

Формат:
Для каждого этапа:
- Название и цель
- Затрагиваемые компоненты
- Критерии готовности (Definition of Done)
- Риски и план отката
- Примерная оценка в story points

Ограничения:
- Нельзя менять контракты публичных API.
- Миграция БД через Liquibase с возможностью отката.
- Команда: 3 разработчика среднего уровня, 2 старших, 30% времени спринта.
